# UI Variation 3: Editorial Grid

This document defines the wireframe for 'Variation 3: Editorial Grid', featuring an asymmetric hero and a Bento-box style feature grid.

## Layout Principles (frontend-design)

- **Spacing:** Use a consistent 8pt grid system.
- **Hierarchy:** Clear distinction between H1 (Hero), H2 (Section), and H3 (Feature).
- **Interactive Elements:** Explicit focus states and semantic HTML roles.
- **Responsive:** Fluid transitions between breakpoints with explicit layout shifts at 768px and 375px.

## Accessibility Notes

- All interactive boxes must have `:focus-visible` rings.
- Images in Bento boxes require `alt` text.
- Icons must be `aria-hidden="true"` or have `aria-label`.
- Heading hierarchy follows `H1` -> `H2` -> `H3` for semantic clarity.
