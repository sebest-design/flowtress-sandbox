# UI Wireframes: Flowtress

This workspace is for low-fidelity wireframes based on the tech-stack docs.

## Goal
Visualize the **Outcome-Driven Portfolio** and **Direct Contact Hub** before high-fidelity implementation.

## Strategy
- Use Markdown/Mermaid for quick flow visualization.
- Reference `docs/PRD.md` for functional requirements (FR-01 to FR-05).
- Reference `docs/architecture.md` for UI components (Bento Grids, Glassmorphism).

## Structure
- `wireframes/flows/` - User flow diagrams.
- `wireframes/layouts/` - Layout sketches and bento grid definitions.
- `wireframes/components/` - Key UI component specs.
